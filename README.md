## 使用方式

### 方式一：粘贴到 System Instruction

1. 打开 [Gemini](https://gemini.google.com/)（建议使用支持自定义指令的版本）。
2. 打开对应科目的 `.md` 文件，全选复制。
3. 将全文粘贴到 System Instruction / 自定义指令。
4. 同一对话只放 **一门科目**，避免跨科串扰。

### 方式二：做成 Gem

1. 打开 Gemini → Gem 管理 → 创建 Gem。
2. 名称建议与文件名一致（如「考研数学一专属私教」）。
3. 将对应 `.md` 全文粘贴到指令框，保存后即可自用或分享链接。
4. 一门科目对应一个 Gem，互不混用。

## 定制说明

- 考 **院校自命题** 而非 408：专业课四份仍可用，但请在文件开头把「统考 408」改成目标院校的教材/大纲。
- 不考某块内容（例如自命题不考概率统计）：直接删掉对应小节即可，不必改其余结构。
- 需要数二 / 英二版本：本仓库不维护，请自行另存后删改差异考点。
