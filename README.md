# 考研 Gemini 专属私教 Prompt

面向 **数学一 + 英语一 + 408 统考** 考生的 Gemini 私教 Prompt 集合。一门科目对应一个 Gem，也可直接粘贴到普通对话的 System Instruction。

## 两层结构

每门科目最终由两个文件组成（目前操作系统已完成，其余科目仍是单文件，逐步迁移中）：

| 层 | 文件后缀 | 内容 | 长度 | 放哪里 |
|---|---|---|---|---|
| 指令层 | `-指令.md` | 身份边界、开场问答、自适应教学策略、输入处理、输出格式、防幻觉 | ≤ 1200 字 | Gem 的「指令」框 |
| 考点库 | `-考点库.md` | 按大纲章节的考点地图、大题批改标准、易混概念对照表 | 不限 | Gem 的「知识」文件 |

拆成两层的原因：Gem 指令框超过 1000~1500 字后，中间的规则会被模型忽略；参考材料放知识文件不占指令预算。

## 使用方式

### 方式一：做成 Gem（推荐）

1. 打开 [Gemini](https://gemini.google.com/) → Gem 管理 → 创建 Gem，名称与科目一致（如「408 操作系统私教」）。
2. 把 `-指令.md` 全文粘贴到「指令」框。
3. 把 `-考点库.md` 上传为该 Gem 的知识文件。
4. 保存。之后每次在这个 Gem 下开新对话，它都自动带着两层内容。
5. 一门科目一个 Gem，不要把多科塞进同一个 Gem。

尚未拆分的科目：把单文件全文粘贴到「指令」框即可。

### 方式二：普通对话的 System Instruction

只有一个输入框时，**考点库在前、指令在后**合并粘贴（模型对末尾的规则记得最牢）：

```bash
cat 计算机考研-操作系统-考点库.md 计算机考研-操作系统-指令.md | pbcopy
```

## 对话节奏建议

- 每个新对话开头，私教会一次性问 4 件事（统考/自命题、进度与掌握程度、教材、薄弱点）。一句话全答或说「跳过」用默认值即可。
- 按**章节**或**阶段**开对话（如「第三章内存管理」「冲刺期错题」），不要每道题开一个新对话，否则会反复触发开场问答。
- 对话中随时可以说「直接讲」跳过引导，或「让我先想」回到引导模式。
- 如果你的 Gemini 支持「已保存的信息」，可以把「考 408、用王道、当前强化期」存进去减少重复回答；本套 Prompt 不依赖该功能。

## 定制说明

- 考 **院校自命题** 而非 408：开场问答时直接告知学校，私教会按你说的教材调整；也可在指令文件第 1 节把「王道 / 408」改成目标院校教材。
- 不考某块内容：删掉考点库中对应小节即可，指令文件不用动。
- 需要数二 / 英二版本：本仓库不维护，请自行另存后删改差异考点。
